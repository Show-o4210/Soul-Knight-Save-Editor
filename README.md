# 元气骑士本地存档工具

本仓库收录两个独立客户端。它们面向不同平台，**功能范围和验证进度并不相同**。

| 客户端 | 目录 | 当前状态 |
| --- | --- | --- |
| Android 本地助手 | [`android/`](android/) | `2.0.0-alpha05` 开发预览；需要 Root，仅处理本机文件 |
| Python 桌面工具 | [`desktop/`](desktop/) | 1.x 系列；将用户准备的存档放入输入目录，结果输出到另一目录 |

## Android 预览版能做什么

- 快捷模式可分别选择解锁现有角色、现有皮肤、将现有角色等级提升到至少 7 级、解锁已有技能条目；四项默认均不勾选。详细模式目前仅支持按角色和皮肤编号选择。
- 识别 `game.data` 与 PlayerPrefs XML；没有 `game.data` 时只支持 XML 中的角色和皮肤。修改前显示预览，写前保存原件，写后复读，并在失败时尝试恢复。
- 可导出限定范围内本地 `.data` 分片与 PlayerPrefs XML 的 ZIP 备份。**当前不能导入 ZIP 或整包恢复，也不能编辑其他 `.data` 分片。**
- 首次写入前要求确认仅操作自己的本地存档；应用没有联网权限。设备上必须为应用授予 Root 权限。

`alpha05` 的公开源码测试有 50 项通过、1 项因缺少私有样本而跳过；Debug APK 构建及 Android lint 通过（0 个错误、39 个警告）。新增的等级与技能逻辑已做私有样本离线校验，**尚未完成该版本的设备写回、游戏实载及重启持久化验收**。角色与皮肤修改此前收到过游戏内有效性反馈。详细边界见[开发状态](docs/development-status.md)和 [Android 说明](android/README.md)。

## Python 桌面版

原有 Python 工程整体移入 [`desktop/`](desktop/)；从该目录启动、构建和运行测试。旧版公开的参考样本仍保留在该目录中，不需要也不应提交自己的存档。使用方式见 [Python 说明](desktop/README.md)。

## 版本说明

`v1.0.1` 是旧客户端版本。`v2.0.0-alpha05` 仅作为 Android 开发预览；预发布 APK 使用调试签名，适合在专用测试设备上验证，不代表已覆盖全部游戏版本或具备正式更新路径。安装前请自行保留原始存档和已安装应用的数据。

本项目与凉屋游戏无关。请仅操作自己有权处理的本地文件。游戏更新可能改变存档格式；存档损坏、进度冲突及账号影响均需使用者自行评估。
