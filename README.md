## 可以做什么

| 想做的事 | 操作例子 |
| --- | --- |
| 角色与皮肤解锁 | 快速模式选择全部现有角色／皮肤；专家模式只选自己需要的条目 |
| 等级、技能与宠物 | 将现有角色升到至少 7 级，保留更高等级；解锁存档中已有的技能、宠物条目 |
| 增加材料、种子等数量 | 在“材料”点一次“每项 +1000”：生物质 25 → 1025；专家模式可以只改生物质 |
| 调整小鱼干与试玩券 | 输入目标数量，例如小鱼干当前 5、输入 20，预览为 5 → 20；留空不改 |
| 磁带、蓝图、设施与饰品 | 磁带数量设为 1、蓝图研究、补齐设施、饰品补齐并充能 |
| 武器获取次数 | 快速模式全部 +8；专家模式搜索武器并单独增加次数。特殊武器的其他资格仍由游戏判断 |
| 武器皮肤 | 快速解锁目录内皮肤；专家模式逐项解锁、选择当前皮肤或明确选用最高品质 |
| 自由修改文件 | 解包到自选目录，自选外部打开方式，修改后导入、预览并重新打包；不校验字段含义，改坏存档由使用者承担 |
| 备份与还原 | 手动／自动备份、ZIP 导入、原件还原、重命名；默认不限数量，可设置上限自动删除最旧备份 |

## 怎么开始

1. 下载上面的 **APK** 并安装。Release 提供已打包的安装文件，直接使用无需配置开发环境；“Source code”压缩包是源码。
2. 进入快速模式，在 Root 管理器中为助手授权；到“存档”页选择游戏版本，点“读取存档”。多个账号时，再选择目标账号。
3. 到“设置 → 备份与恢复”选择助手以外的文件夹，先“备份当前本地存档”。
4. 在角色／物品／武器页勾选或输入，点“预览全部待修改内容”，核对后再点“备份并应用”。
5. 查看操作结果，再进入游戏核对实际进度。读取、刷新和应用修改会关闭所选游戏，请先退出游戏。

不确定按钮作用时，从[图文教学](docs/help/getting-started.md)开始；[自由编辑图解](docs/help/getting-started.md#free-editing)配有当前虚拟机截图，说明导出、自选外部编辑器、导入冲突和最后的写回预览。找不到存档、按钮不可用或修改未生效时，看[常见问题](docs/help/troubleshooting.md)。旧 alpha／Debug 包与正式包签名不同，更新前先看[备份与安装更新](docs/help/backup-and-update.md)。

**2.0.3 新功能的实际使用测试交由用户反馈。** 发布前已有 196 项 JVM 测试通过、5 项私有样本测试跳过；Debug 构建和 lint 通过，设备上 2 项应用选择器 Intent 检查通过。这些检查不包含外部编辑器实际保存、完整目录导出／导入操作或游戏加载效果。自由编辑只检查基础格式和打包，不修复字段、数值或分片关系；修改内容与游戏结果由使用者承担。

**历史 Root 双通道专项检查：2026-10-09。** Pixel 6 / Android 16 上的原生 Root 与 Shizuku Root 通道通过了合成文件读写、备份与事务恢复检查；该专项检查没有修改真实游戏存档。此前 vivo 8.6.0 有角色、皮肤解锁的用户实测反馈。最近模拟器实测日期为上述 2026-10-22。

模拟器实测通过不能代表全部功能、机型、Root 管理器、游戏版本或渠道兼容；OnePlus / APatch 等反馈环境仍待用户复测。详细范围见[验证记录](docs/root-shizuku-validation.md)和[开发状态](docs/development-status.md)。当前正式发布版本为 **2.0.4-rc01**，变更与验证边界见[发布说明](docs/releases/2.0.4-rc01.md)。
