# alpha07：功能分页与渠道存档发现

更新：2026-09-30。Android `2.0.0-alpha07` / versionCode 8。

## 界面

- 主界面分为“存档／角色／物品”。扫描、渠道包名、账号选择与识别结果集中在存档页。
- Tab 使用稳定 ID、标题、页面渲染器注册；数量没有固定为三个。增加功能时注册新页面即可，超出屏幕宽度可横向滚动。各 Tab 的页面状态独立，待修改数据仍由共享模型保留。
- 快速与专家模式共用页面结构；专家物品页仅预留入口，尚未提供物品编辑。
- 备份与恢复放在“设置 → 备份与恢复”。返回顺序为备份 → 设置 → 原功能 Tab。自动写前备份继续执行，未完成事务仍会在主界面提醒。
- 切换 Tab 保留角色和物品选择，取消尚未确认的预览。预览按钮汇总全部页面的待修改内容，并标注目标包名。
- 物品逐项数量列表默认收起，展开后保持 alpha06 的逐项 +1000 行为。

### 保留的后续方案

快速模式按类别提供统一 +1000：材料、通用进化碎片、种子、兑换券各一个按钮；专家模式逐项设置自定义数量。三种特殊数量输入继续独立。**本轮没有实施此数量规则变更。**

## 一个目标版本

- 一个应用包名对应一个候选版本。即使名称相同，也显示各自包名、版本号和识别依据，不合并管理。
- 用户明确选择后才更新目标，不自动认领第一个或唯一候选。之后需点击“扫描所选版本”读取正式基线。
- 切换目标清空旧扫描、账号、角色和物品草稿、预览；保存所选包名供下次使用。
- 普通备份包与写前原件列表按当前包名筛选。待恢复事务是例外：跨版本仍显示并标注所属包名，避免隐藏中断事务；恢复始终使用该事务记录的原目标。
- 当前只搜索助手所在 Android 用户的应用。工作资料、其他 Android 用户及虚拟容器内部的游戏不是跨用户发现范围；同一用户无法并装的同包名 APK 也不会凭空列成多个版本。

## 常规扫描与搜索兜底

常规扫描保持原方案：`/data/user/<当前用户>/<所选包名>` 下，扫描 `shared_prefs/*.xml`，以及 `files/` 根目录和一层子目录的 game/item 文件。XML 按字段识别，不依赖固定 XML 文件名。

未找到存档或需要选择其他已安装版本时，用户主动点击“按特征查找已安装版本”：

1. Root 枚举当前用户安装的非系统应用包名，排除助手自身；优先检查当前包名和疑似游戏包名，然后检查其余候选。
2. 只进入各候选应用的限定目录。XML 先按角色字段文本筛选，再严格解析并核对同账号下多项角色／皮肤信号；单个 `c0_unlock` 不足以认领应用。
3. game 必须能解码并具有角色／皮肤结构；item 必须能解码，含数字 AppVersion 和 materials、seeds、blueprints、tokenTickets 对象。独立 item 可以成为候选，不依赖 XML。
4. 只显示应用名称、包名、版本、识别依据；搜索不关闭候选游戏、不写文件、不自动切换当前目标。
5. 用户选择后进行正常扫描，关闭且核对选中的游戏；文件仍执行已有编辑版本和结构检查。能发现不等于当前全部编辑功能兼容。

### 搜索边界

- 最多 512 个非系统应用，每个应用至多解析 12 个候选文件；XML 文本预筛选小于 1 MiB 的文件，读取仍受既有 4 MiB 单文件限制。
- 两分钟总预算，在文件／应用边界检查；单条 Root 命令仍有 45 秒超时。达到上限或部分文件无法读取时显示不完整检查提示，可以手动填包名正常扫描。
- 搜索可取消；正在等待 Root 命令时每 200 ms 检查取消信号，取消后保留已经发现的候选。
- `.data.new`、云端以及全磁盘递归搜索不在范围内。未申请联网或 QUERY_ALL_PACKAGES 权限；仅声明启动器应用可见性用于显示候选名称，无法取名时回退为包名。

## 代码入口

- `AssistantUi.kt` 的 `workspaceSections`：Tab 注册与渲染。
- `WorkspaceTabs.kt`：稳定 Tab 标识、切页和切换目标时的状态规则。
- `SavesPage.kt`：扫描、当前版本与候选版本界面。
- `SaveDiscovery.kt`：候选元数据、包名排序及内容特征判定。
- `RootStorage.discover()`：有限目录读取、进度、取消和超时。
- `SaveRepository`：按目标包名筛选历史记录；原有事务写回逻辑沿用。

## 验证

JVM 回归覆盖原有 72 项和新增分页、版本切换、备份隔离及内容识别用例，共 82 项；两个私有存档仅离线只读注入。设备验证另外覆盖窄屏扩展 Tab、操作中禁用 Tab、搜索取消，以及实际游戏的只读发现。完整结果与 APK 哈希见交付目录中的验证记录。

用户已反馈 alpha06 经简单游戏测试能产生修改；该反馈不扩充为所有物品或全部渠道验证通过。本轮设备测试不执行游戏存档写回。
