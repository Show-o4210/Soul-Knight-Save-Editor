# alpha13 体验调整与固定路径刷新

日期：2026-10-01。版本：`2.0.0-alpha13` / versionCode 14，测试签名，供用户二测。

用户反馈：alpha12 已进行的样本测试没有发现主逻辑问题。此反馈仅代表已测样本，不能登记为所有条目、版本或正式候选全部合格。

## 1. 连续编辑

- 首次读取并选择账号后，保留目标版本、Android 用户、账号和这批存档的路径，形成当前会话的 `PinnedSaveTarget`。路径书签不保存旧字节，不写入应用长期设置。
- 预览前通过固定路径重新读取文件，以此时内容计算目标值／增加量；确认应用前仍执行原有写前漂移核对和事务备份。
- 写入成功后清空已应用草稿，按相同路径自动刷新，并保留当前功能 Tab。接着进行第二次编辑时无需重新寻找位置。
- 恢复当前目标的备份后也按原路径刷新。游戏已经产生新进度时，既有恢复保护继续拒绝覆盖；固定路径不改变恢复规则。
- “刷新存档”重新读取当前内容并清空草稿。“重新查找”重新发现文件位置。切换版本清空路径书签；退出应用后重新读取。
- 文件缺失、越界或已选择账号消失时停止刷新，不自动替换到另一文件、账号或游戏版本。路径记录仍可重试；用户也可重新查找。成功写入后的刷新失败不会把已完成事务报告为写入失败。

新增接口：`PinnedSaveTarget.from(snapshot, account)`、`SaveScanner.refresh(access, target)`、`RootStorage.refresh(target)`；沿用 `SaveScanAccess` 的停止游戏和校验读取能力，不调用目录搜索。`AssistantState.clearLoaded` 集中清理过时内容，可保留会话书签。原[alpha12 API 档案](core-api-alpha12.md)关于写后必须重新扫描的描述由本页更新。

## 2. 文案与说明层级

- 版本发现按钮改为“扫描”；首次读取为“读取存档”，已固定目标时为“刷新存档”。
- 包名默认隐藏在“手动选择版本”内，展开编辑后按“使用这个版本”提交，不逐字切换目标。
- 功能卡片通过 `HelpTopic`、`HelpButton` 和共用 `Panel(title, help)` 提供“？”说明弹窗；日常界面保留操作、原值、待增加量和必要的不可用原因。
- 物品和武器内部 ID 等详细信息移入卡片说明，搜索仍支持 ID。备份、读取限制、增量／目标值、特殊武器资格等规则可在对应说明查看。
- 预览先显示当前账号、模式、文件数量和分组摘要，技术步骤进入说明，逐项变化仍可展开。

## 3. 导航与动画

- 底部采用紧凑的半透明胶囊，配渐变、边缘高光与滑动选中底色；当前四个 Tab 优先同时展示。更多 Tab 继续支持横向滚动，左右符号不可点击，用作滑动提示。
- 点击按钮或横向滑动可切换相邻页面；竖向拖动不会被当作横向切换。当前选中项会自动保持可见。
- 标题栏副标题仅显示“快速模式”／“专家模式”；未选模式时不显示副标题。
- alpha13 原方向为手指下滑收缩、上滑恢复；用户指出方向相反，已在 [alpha14](header-easter-egg-alpha14.md) 修正为手指上滑、向下浏览时收缩，手指下滑或点击标题栏恢复。只监听列表已消费的滚动，不抢走滚动事件，模式／页面／Tab 切换时恢复展开。
- 模式切换采用轻微纵向位移、缩放与淡入淡出；设置等页面切换采用轻微横移。动效尊重 Compose 的系统动画时长设置。

“毛玻璃”当前为跨 Android 版本的半透明与高光风格，没有为旧 Android 引入不兼容的实时背景模糊依赖。标题滚动方向、透明度、动效节奏与列表舒适度由用户二测继续调整。

## 4. 验证分工

本轮增加固定路径读取新字节、不搜索替代位置、文件缺失、账号改变、越界路径与会话书签清理验证。核心回归、构建和 lint 由 Agent 执行，具体结果在[开发状态](development-status.md)与 APK 构建记录登记。

用户二测重点：

1. 一次读取后连续应用两次数量增量，核对每次从最新数量累加；恢复最近备份后继续编辑。
2. 检查“？”说明、包名折叠和简化文案是否容易理解。
3. 检查四个底部 Tab 是否显眼可达，点击、左右滑动和不可点击提示是否符合预期。
4. 在长列表上下拖动、点击标题栏，检查收缩／恢复；检查快速、专家与入口之间的切换动画。

没有宣称全部功能已验收，也没有把该版本定义为最终交付版本。
