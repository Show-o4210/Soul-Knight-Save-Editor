## 当前版本

当前 Android 发布基线为 **2.0.5-rc05 / versionCode 30**，适配《元气骑士》8.8.0，并保留 8.6.0、8.7.0 支持。更高版本仅开放已明确说明的基础编辑范围，不代表全部功能兼容。详见[发布说明](releases/2.0.5-rc05.md)与[开发状态](development-status.md)。

首次使用 Android 版，请直接阅读[图文教学](help/getting-started.md)。普通用户文档以 `docs/help/` 为准；开发档案和旧版本记录仅描述对应历史阶段，不应用来判断当前界面或能力。
