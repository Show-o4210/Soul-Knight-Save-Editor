# 8.7.0 现有功能适配（2.0.4-dev02）

[开发状态](development-status.md) · [功能说明](help/features.md)

本次开发阶段为 `2.0.4-dev02` / versionCode 23，现已纳入 [`2.0.4-rc01` 社区测试候选](releases/2.0.4-rc01.md)，暂不发布 GitHub Release。保留上一开发版的渠道列表、Root 扫描修复和独立背景。

本文保留 dev02 这一阶段的适配范围。后续 `2.0.4-dev03` 已增加[武器皮肤解锁与当前皮肤选择](weapon-skins-8.7.0.md)，并继续包含以下修复。

## 已实施范围

- 物品与武器接受同账号物品分片中整数型的 `AppVersion=80600` 或 `80700`。默认物品文件的 0、字符串版本、未知未来版本继续拒绝，不使用默认分片替代账号分片。
- 现有 573 项物品目录及增量、目标数量、磁带、蓝图、设施和饰品规则保持一致。8.7 新增的 `trainingJourney` 以及充值计数、商店购买记录和未列入目录的材料保留。
- 宠物同时识别已核对的 8.6 顺序（含 Hide 共 57 项）和 8.7 顺序（58 项）。8.7 只在末尾新增 `FishChipKing`，对应 `p57_unlock`、“鱼干之王”；可见目录为 57 项，Hide 仍排除。只处理已有 XML 键；镜像未知顺序、增加未知 ID、类型异常、多账号对应不明或镜像状态不一致时拒绝宠物预览。旧版不会补造新宠物键。
- 武器目录从 416 项扩充至 419 项，增加 `weapon_hammerhead`（锤头鲨）、`weapon_lighter`（遗迹火焰法杖）、`weapon_void_hand`（手骨回旋镖）。三者名称在 8.6 与 8.7 本地化资源中均已核对。快速全部 +8 和专家逐项增量均支持缺失记录按 0 补入，已有次数继续累加。生成脚本同步维护三个确认的特殊 ID，其他非编号名称不自动扩充。
- 角色、角色皮肤、等级与已有技能继续动态识别。8.7 私有样本含 42 个角色、792 个皮肤、104 项技能，包括咒法骑士的 `ArcaneKnight/Key=2`；没有将新增条目写成固定的全量解锁模板。

武器只修改 `statistic.object2ObtainTime`，蓝图、科技等其他锻造条件仍由游戏判断。`weapon_evolution_data` 中的皮肤／进化记录不参与本轮编辑。湮灭化身蓝图、武器皮肤、战令、亲卫、赛季货币、神话武器等群反馈继续作为后续调查项目。

## 验证方式

公开回归覆盖两个明确版本、未知版本拒绝、两套宠物顺序、鱼干之王定向选择、Hide／缺失键／其他账号保护，以及三把武器的缺失补入与累加。

私有存档不进入仓库。可选的 8.7 回归通过 `-Psave87Baseline=<副本目录>` 注入，目录结构为 `files/` 和 `shared_prefs/`。测试使用真实样本调用 `SaveInspector` 和 `EditEngine.preview`，只在内存中生成快速与专家组合结果；核对角色、全部皮肤、等级技能、宠物、物品和获取次数，再检查未知字段及原件字节保持不变。

构建、设备读取和预览结果以[开发状态](development-status.md)中的本轮执行记录为准。离线预览通过不等于游戏内效果已经验收。
