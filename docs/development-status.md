## Root / Shizuku Root 正式发布（2.0.2）

- [Issue #4](https://github.com/Show-o4210/Soul-Knight-Save-Editor/issues/4) 反馈来自 `2.0.1-rc01(17)`、OnePlus Ace 6T / ColorOS 16 / APatch + FolkPatch。已确认并修复旧目录判断非零退出被统一误报为 Root 操作失败的问题；身份、目标访问、命令、会话、超时与 I/O 失败分开处理。反馈者在 MT / Termux 中的 `su -c` 对照仍只是线索，不能据此认定应用的 stdin 会话存在相同根因，也不能宣称整个 Issue 已解决。
- 原生 Root 保留为默认，增加通过官方 Shizuku API 13.1.5、Provider 和 UserService 的 Root 通道。用户显式选择并授权，服务及 UserService 均确认 UID 0；ADB 模式拒绝游戏私有存档访问，不静默回退原生 Root。
- 扫描、刷新、发现、读取、写回、备份源读取及事务恢复使用所选后端，复用原有识别、编辑、路径限制和应用侧备份。管道传输大文件并校验大小、长度和 SHA-256；未确定写入结果保留事务、不重发或盲目回滚。后端切换使旧快照与预览失效，未完成事务必须先通过原后端恢复。
- **文件读写最近测试时间：2026-10-09。** Pixel 6 / Android 16 / Magisk 上的原生 Root 合成事务测试 2 / 2 通过；Root 启动的 Shizuku 13.6.0 上合成测试 1 / 1 通过。后者实际传输 2 MiB + 137 字节，重绑定、原件备份、写回、恢复及 owner / mode / SELinux context 复读通过；设备测试只操作助手自身合成目录。
- 发布前开发候选的 JVM 回归 167 项：162 通过、5 个未提供私有样本的测试跳过、0 失败／错误；Debug 和仪器测试 APK 构建、lintDebug 通过，lint 为 0 errors / 48 warnings。按用户要求停止继续设备测试并转入正式打包发布；完整执行记录见 [开发候选验证档案](root-shizuku-validation.md)。
- **未修改真实游戏存档，未验证游戏内效果，不保证实际可用。** OnePlus / APatch / FolkPatch 反馈设备及其他机型、Root 管理器、渠道仍待用户复测。Issue #4 保持开启，请先下载正式 2.0.2 检查授权、诊断和读取，再反馈结果。存档适配基准仍为元气骑士 8.6.0；此前 vivo 用户实测记录见下文。
- 下载、更新与首次验证步骤见 [2.0.2 发布说明](releases/2.0.2.md)。
