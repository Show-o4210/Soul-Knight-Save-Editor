# alpha14 标题方向修正与 SHOWCHEER 彩蛋

日期：2026-10-01。版本：`2.0.0-alpha14` / versionCode 15，调试签名，仍为测试候选。

用户反馈 alpha13 体验效果良好，同时指出标题收缩的滑动方向相反；这不扩大此前样本验收的范围。本轮修正方向并移植用户提供的彩蛋。

## 标题收缩

- 手指上滑、向下浏览列表时，标题收缩。
- 手指下滑、向上浏览列表时，标题展开；点击标题也展开。
- 继续只监听列表实际消费的拖动，不抢走列表滚动；模式、页面和 Tab 切换时展开。

本规则更新 [alpha13 体验档案](experience-alpha13.md)中的原始方向描述。

## 彩蛋入口与效果

- 连续点击标题栏 7 次触发，相邻点击间隔不超过 1.2 秒；超过间隔重新计数。
- 第 4／5／6 次出现渐进提示。同次打开中触发过后，3 次点击可重播；重新打开后恢复 7 次。
- 标题单击仍可展开收缩栏。“模式”“设置”“返回”等按钮执行自身操作，不累计标题点击；业务操作进行中不触发彩蛋。
- 保留 `SHOWCHEER` 签名。字母先散落、旋转与碰撞，然后聚拢；最终出现签名、金绿粒子和欢迎语。播放约 8 秒，点击任意位置或返回可提前退出。
- 首次文案为“骑士档案馆 · 保持好奇。”，历史已发现后为“欢迎回来，骑士。”。仅保存发现标记，不降低下次打开的点击门槛。
- 系统关闭动画时直接展示静态签名；应用进入后台时暂停计时。尺寸改变后按新画布重新播放。

来源为用户提供的桌面 `SHOWCHEER彩蛋` 目录，参考 `showcheer-core.js` 的固定步长物理规则和 `reference/ShowcheerEasterEgg.original.kt` 的 Compose 呈现，未修改参考目录。没有新增依赖或联网权限。

## 实现接口

- `CheerTrigger.tap(now)`：独立处理连续点击、提示、会话重播与首次发现。
- `CheerPhysics.advance(seconds)`：以逻辑像素、1/120 秒固定步长更新字母；单帧时间最多计入 0.1 秒，兼容不同刷新率。
- `ShowcheerEgg(firstDiscovery, onDismiss)`：全屏 Compose 弹层与生命周期处理；不改变当前模式、Tab、目标存档或编辑草稿。
- `AssistantModel.hasDiscoveredCheer/markCheerDiscovered`：沿用应用偏好存储记录历史发现状态。
