# 2.0.5-rc02 · 武器进化与存档兼容修复

2026-10-23，Android 7.0 及以上，适配元气骑士 **8.7.0**，保留 8.6.0 支持。

相比上一公开版本 **2.0.4-rc01**：

- 新增普通武器进化，以及 28 把神话武器的解锁、升级。
- 补充湮灭化身蓝图、角色技能材料、古代武器残页和训练积分；自由编辑支持 XML 导出与原路径写回。
- 新增角色、皮肤、技能重新锁定：优先恢复解锁前原值，保留基础内容，未知锁值跳过。
- 增加游戏运行检测，前台或后台运行时暂停存档操作；修复文件变化、Root 超时引发的持续等待。
- 修复光速虚拟机旧 Android 命令兼容，原生 Root 与 Shizuku Root 自动启用备用读取方案。
- 修复 B 站服材料修改不生效：支持 `.data.new` 的扫描、备份与读写，修正账号绑定，保留未选内容和原读取模式。

**2026-10-23 模拟器测试通过**：武器进化、神话武器由维护者验收；B 站 8.7 原生 Root 已验证材料修改生效、未选材料保留。光速两通道已验证读取，其他设备与渠道继续收集反馈。

沿用正式签名，可覆盖更新同签名版本。使用前请保存并彻底退出游戏。
