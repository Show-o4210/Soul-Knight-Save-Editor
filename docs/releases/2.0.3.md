## 本次修改

- 增加第三个“自由编辑”模式：解码 `.data` 到自选本地目录，通过应用选择器自选外部打开方式，修改后返回助手导入、预览并重新打包。没有内置文本编辑器。支持已知 XOR／DES、明文 JSON；未知编码以原始字节导出。保留大整数和未知字段，不套用快速／专家模式的业务白名单。
- 导入先按 SHA-256 比较，再按文件名前缀匹配。重复内容去重，多份不同修改可选择或跳过；无法匹配的多余文件报告忽略，不删除，也不新增到游戏目录。写入位置由应用私有导出记录确定。
- 完成备份 ZIP 导入和原件还原。还原先备份当前文件，再覆盖备份内原文件；相关账号已有的 `OpenRijTest`、`OpenNewtonJsonTest` 读取开关强制设为 0，即使原件为 1。缺失键不新增，备份原件不变；不处理 `.data.new`，目标文件须存在，不合并账号或恢复完整应用数据。
- 备份可重命名，默认从“存档#0”递增编号。默认不限数量，可在设置填写每个游戏的保留上限；超出时删除最旧的应用内备份。手动快照与修改前原件合计，未完成事务及外部副本不自动清理。
- 保留写前漂移检查、自动备份、权限保留、写后复读、失败回滚和中断恢复。主动还原允许覆盖后续进度；自动故障恢复继续拒绝覆盖事务之外的变化。

操作说明：[自由编辑](https://github.com/Show-o4210/Soul-Knight-Save-Editor/blob/main/docs/help/free-editing.md) · [备份、还原与更新](https://github.com/Show-o4210/Soul-Knight-Save-Editor/blob/main/docs/help/backup-and-update.md)。

## 安装与反馈

沿用原正式证书，可覆盖更新正式 2.0.0／2.0.1-rc01／2.0.2。早期 alpha、Debug 和开发候选签名不同，不能直接覆盖；卸载前请处理未完成事务，导出内部需要的备份，妥善保留游戏原件。2.0.3 可导入本工具导出的备份 ZIP；自由编辑的私有来源记录会随卸载丢失。

首次使用先核对包名、Android 用户及账号，保留外部备份，再分别试验需要的功能。反馈请包含助手版本、游戏版本／渠道、设备、Root 工具、访问通道、外部编辑器及具体提示；请勿公开个人存档或账号信息。
