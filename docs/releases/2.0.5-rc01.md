## 自由编辑 XML 的对应与写回

XML 同样使用导出内容哈希、文件名前缀和冲突选择规则；写回目标由助手私有导出记录固定，外部重命名或编辑说明文件不能指定任意设备路径。不把未匹配 XML 作为新文件塞进游戏目录。

导入时保留用户的其他 XML 编辑；对应账号已有的本地读取开关仍强制设为 **0**，即使导入内容为 1。缺失开关不会自动补建。仅处理 XML 基础格式与原路径写回，不修复游戏数值、字段含义或跨分片镜像关系。

XML 与 `.data` 一起使用现有的预览、备份、写前漂移检查、权限保留、复读验证及失败回滚。返回助手、导入比较或打开预览均不会写回；最后点击“备份并应用”才执行。`.data.new` 继续不读取、不修改。

已有 2.0.4 的导出记录不含 XML 时，需要重新读取并导出，才会把 XML 加入这轮编辑；旧记录仍按原有文件范围工作。逐步操作见[自由编辑帮助](../help/free-editing.md)，旧界面的[九张图解](../help/getting-started.md#free-editing)继续保留并标明版本。

## 社区反馈重点

1. 蓝图研究和新增材料／积分能否在 8.7 游戏中正确显示，重启后是否保留。
2. 普通武器进化是否生效，已有更高等级、皮肤选择及未选武器是否保留。
3. 神话武器解锁、等级 0～3 的显示是否符合预期，是否影响已有神话武器或其他物品。
4. 自由编辑导出目录是否含预期 XML，能否使用自选应用保存；单独编辑 XML 与混合导入是否都能预览到正确原路径。
5. XML 的其他修改是否保留，对应账号已有读取开关是否为 0；格式错误、源文件变化或多份修改冲突是否有清楚提示。

反馈请带助手版本、游戏版本／渠道、设备、Root 方式、访问通道、具体操作及提示；请勿公开上传原始存档、账号或令牌。
