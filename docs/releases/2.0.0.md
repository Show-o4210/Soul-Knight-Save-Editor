# 骑士档案馆 2.0.0

Android 客户端首个正式发布里程碑，基于 alpha14 的开发与样本反馈整理。后续功能和体验仍会继续完善。

## 主要功能

- **角色**：解锁已有角色、皮肤、技能和宠物；低于 7 级的角色提升至 7 级，保留更高等级。
- **物品**：材料、通用武器进化碎片、种子、兑换券每项 +1000；小鱼干和两种角色试玩券独立输入；磁带获取、蓝图研究、设施补齐和饰品充能。
- **武器**：使用游戏内试验确认的 `object2ObtainTime` 增加获取次数，快速模式统一 +8；特殊武器仍须满足游戏自己的其他条件。
- **专家模式**：角色／物品／武器按条目选择；支持适用数量条目的目标值或自定义增加量，武器仅增加次数。
- **存档与备份**：渠道版本扫描和选择、会话固定路径、连续编辑自动刷新、修改预览、原件备份、写后核对与失败恢复；可导出 ZIP。
- **体验**：四个功能 Tab、卡片问号说明、折叠高级选项、独立结果弹窗、收缩标题和模式动效。

## 使用条件与边界

- Android 7.0 及以上，需要 Root，仅操作自己设备上的本地文件。
- 物品目录和武器配对版本核对以 **元气骑士 8.6.0 / AppVersion 80600** 为基准；不宣称全部渠道或游戏版本通用。
- 其他未确认 `.data` 仅用于备份，不编辑 `.data.new`。ZIP 支持导出，尚不支持导入或整包恢复。
- 扫描与刷新会关闭选中的游戏进程；先退出游戏再操作。同设备多个游戏版本需选择其中一个。
- 用户已反馈代表性样本、宠物及两把武器 +8 实验有效；完整目录、所有渠道与全部专家条目并未逐项游戏验收。
- 项目维护者的 Root 真机测试中，游戏本身可能闪退，即便不修改存档也会发生；建议使用自己可备份的虚拟机环境。此反馈不表示编辑器在所有真机均无法运行。
- Python 桌面版继续独立保留于 `desktop/`；本次附件只发布 Android APK。

## 从 alpha 测试包迁移

**正式签名与历史 alpha 调试签名不同，不能直接覆盖安装。**

1. 在旧助手的设置／备份页，把当前存档和需要保留的修改前原件导出到应用以外的目录，并额外备份该目录。
2. 确认没有未完成的写回事务；如有，先在旧助手中处理恢复。
3. 保留游戏原始文件，卸载旧助手后安装正式 APK，重新授权 Root、选择版本并读取存档。

卸载助手会删除它内部的备份、设置与草稿；外部 ZIP 目前不能导回助手恢复列表，必要时需自行恢复其文件。卸载助手不会迁移或清理游戏存档。以后同包名、同正式密钥且更高 versionCode 的正式版本可按 Android 更新流程覆盖安装。

## 文件与验证

附件为 `SoulKnightSaveEditor-2.0.0.apk`，附 `SHA256SUMS.txt` 和公开签名证书 `release-certificate.pem`，用于核对文件和发布身份。私钥及密码不随源码或发布附件提供。
