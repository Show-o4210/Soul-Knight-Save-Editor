# 2.0.5-rc05 · 8.8.0 适配

Android 发布基线：**2.0.5-rc05 / versionCode 30**。本说明仅记录仓库中可确认的版本内容；未在原始发布记录中登记的构建日期、自动测试数量或设备测试项目不作推测。

## 本次内容

- 适配《元气骑士》8.8.0，保留 8.6.0 和 8.7.0 支持。
- 对高于已核对版本的存档，仅开放已有的已知材料、兑换券和武器获取次数；缺失条目不补建。此基础兼容不等于角色、宠物、皮肤、武器进化或神话武器等功能全部兼容。
- 打开游戏版本列表时刷新已保存渠道的安装版本。
- 页眉更换新标识；“加入我们”可打开 GitHub 仓库、QQ 交流群和赞助页面。

## 安装与更新

需要 Android 7.0 及以上和 Root。沿用原正式签名，可覆盖更新同包名、同正式签名且 versionCode 更低的正式发布版本。历史 alpha／Debug 包签名不同，迁移前先处理未完成事务并把需要保留的助手备份导出到应用外，详见[备份与更新](../help/backup-and-update.md)。
