# 骑士档案馆 2.0.1-rc01 · vivo 渠道修复

Android 正式修复发布，2026-10-04 按用户要求由预发布转正并设为最新正式版。GitHub 标签 `v2.0.1-rc01`，APK 内版本 `2.0.1-rc01` / versionCode 17；保留已实测 APK、标签和文件名，因此版本字符串仍带 `rc01`。使用与正式 `2.0.0` 相同的签名；后续功能和体验继续完善。

## 本次修复

- 支持 vivo 渠道服 `com.liangwu.yuanqiqishi.vivo` 在 8.6.0 样本中使用的 16 位小写十六进制账号，解决“能扫描到游戏，但无法编辑”的问题。
- XML 角色识别、物品与武器分片配对、路径校验和固定路径刷新共用账号规则，原有数字账号继续支持。
- 按所选账号读取真实文件，保留版本核对、账号隔离和写回事务；初始化默认文件不替代账号分片，`.data.new` 不参与编辑。

## 验证范围

- **用户已在 vivo 渠道实测角色、皮肤解锁成功。**
- 核心回归 123 项：119 通过、0 失败／错误，4 项旧可选私有样本未提供而跳过；新增 vivo 回归 5 项全部通过。
- vivo 私有样本中的角色、等级技能、宠物、物品、武器读取及代表性组合修改通过离线检查；除上述角色和皮肤外，本次其余 vivo 功能仍待游戏内验证。
- Release 构建（含 R8、lintVital）、正式签名与版本核对通过。本轮未重跑完整 lintRelease。
- 其他渠道继续等待社区反馈；物品与武器目录仍以元气骑士 8.6.0 / `AppVersion=80600` 为基准。

## 安装与更新

- Android 7.0 及以上，需要 Root，仅处理用户自己的本地存档。
- 可直接覆盖更新正式 `2.0.0`，保留助手数据；**更新后请重新选择 vivo 版本并读取存档**，编辑前先导出原始备份。
- 历史 alpha 调试包签名不同，不能直接覆盖；需先导出助手内部所需备份并处理未完成事务，再迁移，步骤见 [2.0.0 安装说明](https://github.com/Show-o4210/Soul-Knight-Save-Editor/blob/main/docs/releases/2.0.0.md)。
- 扫描、刷新和写入会关闭所选游戏进程。ZIP 目前只支持导出，不能导入或整包恢复。
