## 快速／专家原有配图（2026-10-10）

以下原有配图于 **2026-10-10** 通过 ADB 从 Pixel 6 / Android 16 截取，保持原始 PNG，仅在 Markdown 中缩小显示。设备当时安装的是同版功能的 `2.0.2-root01` Debug 候选，下载入口当时为正式签名 `2.0.2`。不是游戏运行效果图；当前下载版本以项目首页为准。

| 图片 | 内容与数据来源 |
| --- | --- |
| modes.png | 模式入口 |
| access-settings.png | 原生 Root 与 Shizuku Root 设置；身份检查不代表游戏目录可读 |
| saves.png | 从独立演示目录读取后的存档页 |
| backups.png | 备份按钮展示，没有执行备份或恢复 |
| characters.png | 两个演示角色；没有技能／宠物可编辑项，所以部分按钮不可用 |
| items-draft.png | 演示材料 +1000 的待修改草稿 |
| expert-items.png | 专家物品页，未选择任何条目 |
| preview.png | 演示草稿的逐项预览，没有点击“备份并应用” |

角色、物品与预览数据是单独构造的样例，位于设备上的仪器测试包目录，没有读取真实账号内容用于这些图片。功能页通过 Shizuku Root 读取演示文件。本次设备上的原生 Root 读取所选游戏未找到应用数据，未据此登记真实游戏目录验证通过。截图后核对四份演示文件 SHA-256 不变，并移除演示文件、恢复原选择的游戏、原生 Root 和快速模式。

这组旧截图不是文件修改测试，当时的文件修改测试记录为 **2026-10-09**。历史范围见[验证记录](../root-shizuku-validation.md)，最近版本与维护者实测反馈见[开发状态](../development-status.md)。

## 自由编辑配图（2026-10-22）

[对应逐按钮图解](../help/getting-started.md#free-editing)。通过 ADB 从现有 **雷电模拟器 / Android 9 / emulator-5554** 截取，原始 PNG 为 **1080 × 1920**，未裁切、改绘或添加假界面，文档中仅缩小显示。覆盖安装既有正式签名 **2.0.4-rc01 / versionCode 25**，APK 与已发布附件相同，使用原生 Root 读取独立演示目录。

| 图片 | 内容与数据来源 |
| --- | --- |
| free-entry.png | 入口下方的黑色自由编辑卡片，与紫色专家模式区分 |
| free-export.png | 本地导出目录、全选／清空选择、导出计数按钮 |
| free-sources.png | 两个明文 JSON 演示文件及一个未识别编码的原始字节文件 |
| free-file-chooser.png | “选择编辑文件的应用”系统界面；列表来自模拟器已有应用 |

| free-import.png | 打开目录、两种导入方式与逐文件打开入口 |
| free-review.png | 编辑器自动生成的 `.bak` 按哈希识别，修改副本按前缀匹配，`notes.txt` 未匹配并忽略 |

来源为已安装仪器测试包 `com.example.soul_knight_save_editor.test` 中本轮新建的独立目录：`inventory.data`、`profile.data`、`opaque.data` 及配套演示 XML。文件内容均为人工样例，公开截图未使用真实账号或存档内容；数字 `20261022` 是演示目录的日期，哈希前缀来自演示文件。

实际通过外部编辑器把导出副本中的 `sample` 改为 `example` 并保存，核对其保存结果；编辑器自动产生了 `.bak`。随后仅对导出副本构造两份不同的 `profile` 修改和一个未匹配文本文件，用于截图说明冲突、跳过和忽略规则。解码导出、外部应用打开／保存、导入比较、版本选择、预览展开与取消均实际操作；未点击“备份并应用”，未写回演示来源或真实游戏，也未启动游戏。

截图后核对 **4 / 4 份演示来源、34 / 34 份游戏 `.data` 与 XML 的 SHA-256 不变**，恢复助手原设置和游戏选择；只清理本轮创建的演示目录、导出副本和助手导出记录，保留原有数据。此记录用于说明图解来源和操作范围，不把演示副本编辑等同于游戏加载验收。维护者 2026-10-22 的模拟器实测反馈另见[发布说明](../releases/2.0.4-rc01.md)。
