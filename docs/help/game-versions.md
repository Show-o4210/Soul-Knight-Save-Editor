# 游戏版本与渠道切换

[帮助中心](README.md) · [首次使用](getting-started.md) · [功能说明](features.md)

## 选择游戏渠道

存档页默认提供 `com.ChillyRoom.DungeonShooter` 原版。点“切换游戏版本”时，列表会刷新已保存渠道的安装版本。选好渠道后点“读取存档”（自由编辑中为“读取 .data 文件”）。列表保留原版和上次选择，重启后不用重新输入包名。

首次使用其他渠道时，可在“查找游戏版本”点“扫描全部游戏版本”。扫描检查已安装应用的本地存档特征，不关闭游戏、不修改文件；找到的版本自动加入保存列表，不自动替你切换。未发现时，也可展开“添加其他渠道（包名）”，输入实际包名并保存。以后从列表直接选择。

读取只处理当前选中的包名，不合并多个渠道或账号的存档。切换会清空旧存档、位置记录和待修改草稿，需要重新读取；有未完成事务时先恢复，再切换。卸载了某个渠道后，它仍可能保留在列表中，读取时会提示重新选择，不能把这个提示当作 Root 授权失败。

## 游戏版本兼容范围

当前 Android 发布基线为 **2.0.5-rc05 / versionCode 30**：

| 游戏版本 | 当前支持边界 |
| --- | --- |
| 8.6.0 | 已核对的基础编辑与对应版本目录；具体功能仍受文件、账号和条目存在情况限制 |
| 8.7.0 | 已核对的基础编辑，并有武器皮肤、普通武器进化、神话武器等专项目录记录 |
| 8.8.0 | 当前适配版本；已有原版 Android 9 模拟器的材料、兑换券、武器获取次数读取／预览记录，铁矿和获取次数另有游戏内确认 |
| 高于 8.8.0 | 仅开放存档中已有且数值有效的已知材料、兑换券和武器获取次数；缺失条目不补建，不承诺角色、皮肤、宠物、进化或神话武器等全部功能兼容 |

“已核对版本”不代表每个渠道、设备和每个条目都经过游戏内验收。功能按钮是否可用，还取决于对应账号分片、格式、结构和已确认目录。详细验证边界见[开发状态](../development-status.md)和[已知问题与待验证范围](../known-issues.md)。
