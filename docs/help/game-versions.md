# 游戏版本与渠道切换

[帮助中心](README.md) · [首次使用](getting-started.md)

本页功能始于 `2.0.4-dev01`，现已纳入 [`2.0.4-rc01` 社区测试候选](../releases/2.0.4-rc01.md)；正式 2.0.3 尚无保存渠道列表的入口。

存档页默认提供 `com.ChillyRoom.DungeonShooter` 原版。点“切换游戏版本”，选择已保存的渠道，再点“读取存档”（自由编辑中为“读取 .data 文件”）。列表始终保留原版，也会保留上次选择，重启后不用重新输入包名。

首次使用其他渠道时，可在“查找游戏版本”点“扫描全部游戏版本”。扫描检查已安装应用的本地存档特征，不关闭游戏，不修改文件；找到的版本自动加入保存列表，不自动替你切换。未发现时，也可展开“添加其他渠道（包名）”，输入一次实际包名，点“保存并切换”。以后从列表直接选择。

该开发版也修复了 Android 9 部分系统因不支持旧 `find` 文件大小参数而跳过游戏的问题，仍保留 XML 的大小限制和权限错误提示。

读取只处理当前选中的包名，不合并多个渠道或账号的存档。切换会清空旧存档、位置记录和待修改草稿，需要重新读取；有未完成事务时先恢复，再切换。卸载了某个渠道后，它仍保留在列表中，读取会提示重新选择，不能把这个提示当作 Root 授权失败。

选对包名与游戏版本适配是两回事。2026-10-22 在虚拟机上使用原生 Root 成功读取默认渠道 8.7.0；物品／武器的快速与专家目录仍按已确认版本检查。本轮只改渠道选择与视觉样式，不扩大游戏编辑规则。
