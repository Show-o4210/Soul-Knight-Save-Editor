# 功能说明与例子

[帮助中心](README.md) · [按钮图文教学](getting-started.md)

Android 2.0.5-rc02 的快速模式适合按类别准备修改；专家模式适合只改某个条目。两者共用预览、自动备份和写回检查。2026-10-23 模拟器测试通过，游戏版本为 8.7.0；下面描述已实现的操作，不表示全部条目、设备或渠道均已验收。

正式版 `2.0.3` 增加[自由编辑](free-editing.md)：不内置文本编辑器，将 `.data` 解码导出到本地目录，自选外部应用修改后再导入打包。它不套用下表的业务白名单，不修正用户编辑的字段关系；游戏内结果由用户承担。写前备份与事务恢复仍保留。

当前正式发布版本支持已核对的 **8.7.0 / 80700**：沿用角色与皮肤动态识别，物品与武器保留 80600 支持；宠物增加“鱼干之王”，武器补齐锤头鲨、遗迹火焰法杖、手骨回旋镖。战令、亲卫等扩展未包含，详见[适配记录](../compatibility-8.7.0.md)。

2.0.4 起支持[武器皮肤](../weapon-skins-8.7.0.md)：“武器”页切换到“武器皮肤”，快速解锁已确认目录并保留当前选择，专家可逐项解锁、换肤或明确选择可用的最高品质。8.7 支持 184 个皮肤、8.6 支持 176 个；不改变进化等级，品质和选择索引分别显示。

**2.0.5-rc02** 已发布，包含下述材料、普通进化、神话武器与 XML 自由编辑，以及重新锁定、游戏运行检测和新格式兼容修复。

| 功能 | 快速模式 | 专家模式 | 要留意什么 |
| --- | --- | --- | --- |
| 角色、皮肤 | 分别选择全部解锁 | 逐项选择 | 只处理识别出的现有条目 |
| 等级 | 全部至少 7 级 | 选择角色后至少 7 级 | 原有 9 级仍为 9；暂不提供自由等级 |
| 技能 | 解锁已有技能条目 | 逐项选择已有技能 | 不新增存档没有的技能条目 |
| 宠物 | 解锁已有宠物 | 按宠物选择 | 核对 8.6／8.7 两套映射；只处理已有账号键，排除 Hide |
| 材料、通用进化碎片、种子、兑换券 | 分类每项 +1000，可重复／撤销一次 | 单项或选中批量，目标数量／增加量 | 只开放已确认目录，不是游戏所有资源 |
| 小鱼干、普通／英雄试玩券 | 分别输入目标数量 | 单项或选中批量设置目标数量 | 留空不改，0 清零 |
| 磁带 | 全部获取至 1 | 选择磁带设为 1 | 原来超过 1 也会设为 1 |
| 蓝图 | 全部研究 | 选择需要研究的蓝图 | 已研究的保留 |
| 设施 | 补齐列表 | 选择需要补入的设施 | 保留已有记录 |
| 饰品 | 补齐并充能至 100 | 选择饰品补齐／充能 | 保留已有佩戴、图纸与符文；不提供换装编辑 |
| 武器获取次数 | 全部 +8 | 搜索名称／ID，选中 +8 或自定义非负增量 | 不下调次数；蓝图、科技等其他资格仍由游戏判断 |
| 武器皮肤 | 解锁当前版本确认目录，保留当前选择 | 搜索并逐项解锁、选择当前皮肤／原皮肤、显式选最高品质 | 保留进化等级，品质与索引分别比较 |

## 2.0.5 新增功能

| 功能 | 怎么用 | 范围 |
| --- | --- | --- |
| 湮灭化身蓝图 | 快速勾选全部蓝图研究，或专家搜索“湮灭化身”单选研究 | 只更新蓝图研究状态，不代替获取次数等其他资格 |
| 技能与古代武器材料 | 快速分类每项 +1000，可撤销；专家逐项设置目标或增量 | 8 本角色材料与古代武器残页，共 9 项 |
| 训练积分 | 独立分类每项 +1000，或专家设置目标／增量 | 训练补给商店积分 `material_bp_point`，不是战令经验或等级 |
| 普通武器进化 | 选择当前版本确认可进化的武器，准备进化 | 8.6 共 118 把、8.7 共 121 把；`Level=0 → 1`，已有正等级保留 |
| 神话武器 | 分别准备解锁或升级到满级 | 28 把；解锁记录为等级 0，满级 3；与普通武器进化、获取次数、皮肤独立 |
| XML 自由编辑 | 读取后选择现有 XML，与 `.data` 一起导出，或仅选 XML；保存后导入预览 | XML 原文导出并写回原路径；含新格式时保留原读取模式，详见[自由编辑规则](free-editing.md) |

技能与古代武器材料包括接引大书、复苏大书、精灵之泪、法力结晶、传承族徽、便携式超时空联系装置、珍藏的番号牌、特别行动令、古代武器残页。它们与训练积分分组，物品目录合计 584 项、264 张蓝图。详细目录见[进化与神话武器记录](../weapon-upgrades-8.7.0.md)。

皮肤解锁本身仍保留进化等级；同时选择普通进化时，才会额外生成对应 `Level` 的变化。神话武器使用物品分片中的 `mythicWeapons`，没有把其等级套入皮肤分片。

## “设为”与“增加”的区别

以生物质原有 25 为例：

| 你的输入 | 预览结果 |
| --- | --- |
| 增加量 100 | 25 → 125 |
| 目标数量 100 | 25 → 100 |
| 目标数量 0 | 25 → 0 |
| 留空／增加量 0 | 不修改 |

同一项的目标值与增量互斥。当前只接受非负整数并检查整数溢出，这不是对游戏允许数量上限的承诺。先看逐项预览，再决定是否应用。

## 存档不同，可用按钮也不同

角色与宠物根据识别出的角色文件、账号 XML 判断；物品根据同账号物品分片判断；武器需要统计分片及同账号物品分片核对版本。**物品可以独立于角色文件使用**，角色读不到不一定代表物品也不可用。

当前物品与武器支持已核对的 **8.6.0 / 80600、8.7.0 / 80700**。文件缺失、账号不能配对、版本或结构不符时，相应功能会提示不可用；不要通过随意重命名另一账号文件来绕过检查。快捷武器操作会补入已确认目录中武器缺失的获取记录，专家模式也受该目录限制。武器皮肤另需同账号的进化分片，不使用默认分片代替。

## 角色、皮肤和技能重新锁定（2.0.5）

在“角色”页切换“解锁／重新锁定”。快速模式按角色、皮肤、技能批量准备；专家模式逐项选择。修改仍进入共享预览，确认后通过原有事务写回。

- 优先使用同游戏包名、同 Android 用户、同账号、同 XML 位置的备份原件，按新到旧查找各键最近可确认的锁值。已解锁值不会覆盖更早记录的锁值。
- 没有可用原件时，仅 B 站渠道 `com.knight.union.bili`、已确认的 8.7.0 使用本次采集的锁值参考；其他渠道或未知版本不套用这份表。参考包含 749 个皮肤的 29 种原始整数锁值，不能统一改成 0。
- 基础角色、每个角色的基础皮肤和基础技能保留。锁值未知、XML／`.data` 镜像冲突或必要字段不能核对时跳过并显示原因，不补造记录。
- 重新锁定需要对应的 XML 和 `game.data`，同步修改角色、皮肤、技能镜像。当前使用内容受到影响时回退到基础项，并在预览列出；等级与其他进度保留。
- 自动备份仍按现有设置保留。若旧备份已清理且没有适用参考，原锁值可能无法确认；先保留解锁前备份，勿用其他账号或渠道的文件代替。

原值来源、参考范围和当前选择字段详见[重新锁定说明](../character-relocking.md)。

## 新格式存档（2.0.5-rc02）

识别同账号的 `.data` 与 `.data.new` 物品、统计和武器进化分片；共存时按实际绑定的读取模式选择基准，物品与武器增量只计算一次，再同步所选内容到已有对应分片。读取模式不明且两份内容不同时停止自动选择。各文件保留自己的编码与未修改字段，不把整份旧 JSON 覆盖到新文件。多处同名来源仍拒绝自动选择。

手动备份包含本地 `.data`、`.data.new`、原生 `_temp` 恢复候选和识别到的 XML；自动原件包含本次实际涉及的两种格式。自由编辑也保留原编码，并同步已有同路径的新旧分片，详见[自由编辑说明](free-editing.md)。B 站服按 XML 中明确记录的账号映射识别读取模式，不猜测其他账号。含新格式的正常编辑保留原模式；手动还原继续按约定归零已有开关。

## 目前没有的功能

- 完整应用数据恢复或跨账号复制。2.0.3 支持本工具 ZIP 的限定范围导入与还原，2.0.5-rc02 补齐新格式，详见[备份说明](backup-and-update.md)。
- 删除 `.data.new` 或独立的“强制读取本地”按钮。
- 云端登录、上传、下载或自动同步；需要使用游戏自己的云存档功能。
- 快速／专家模式没有自由角色等级、武器次数下调、饰品换装／符文编辑等预设操作。自由编辑可手动改文件，但不保证这些修改有效，也不修复分片关系。
- 赛季币、亲卫、战令等级／高级手册 `hasBuy`、累充鱼干计数等专用入口，本版也未加入。

本地读取开关的处理见[专门说明](local-data-reading.md)，备份与恢复范围见[备份说明](backup-and-update.md)。**最近模拟器实测：2026-10-23，通过，适配 8.7.0。** 原生 Root／Shizuku Root 合成文件双通道专项检查日期仍为 2026-10-09；其他设备与渠道继续收集反馈，具体范围见[发布说明](../releases/2.0.5-rc02.md)和[开发状态](../development-status.md)。Python 桌面版有独立功能范围，见[桌面版说明](../../desktop/README.md)。
