# 功能说明与例子

[帮助中心](README.md) · [按钮图文教学](getting-started.md)

Android 2.0.3 的快速模式适合按类别准备修改；专家模式适合只改某个条目。两者共用预览、自动备份和写回检查。下面描述已实现的操作，**不表示全部条目已经通过游戏内验证**。

正式版 `2.0.3` 增加[自由编辑](free-editing.md)：不内置文本编辑器，将 `.data` 解码导出到本地目录，自选外部应用修改后再导入打包。它不套用下表的业务白名单，不修正用户编辑的字段关系；游戏内结果由用户承担。写前备份与事务恢复仍保留。

未发布的 `2.0.4-dev02` 另外支持已核对的 **8.7.0 / 80700**：沿用角色与皮肤动态识别，物品与武器保留 80600 支持；宠物增加“鱼干之王”，武器补齐锤头鲨、遗迹火焰法杖、手骨回旋镖。此适配不包含武器皮肤、战令或亲卫等新功能，详见[适配记录](../compatibility-8.7.0.md)。

后续开发版 `2.0.4-dev03` 新增[武器皮肤](../weapon-skins-8.7.0.md)：“武器”页切换到“武器皮肤”，快速解锁已确认目录并保留当前选择，专家可逐项解锁、换肤或明确选择可用的最高品质。8.7 支持 184 个皮肤、8.6 支持 176 个；不改变进化等级，品质和选择索引分别显示。该功能尚未进入上述正式版下载。

| 功能 | 快速模式 | 专家模式 | 要留意什么 |
| --- | --- | --- | --- |
| 角色、皮肤 | 分别选择全部解锁 | 逐项选择 | 只处理识别出的现有条目 |
| 等级 | 全部至少 7 级 | 选择角色后至少 7 级 | 原有 9 级仍为 9；暂不提供自由等级 |
| 技能 | 解锁已有技能条目 | 逐项选择已有技能 | 不新增存档没有的技能条目 |
| 宠物 | 解锁已有宠物 | 按宠物选择 | 按 8.6.0 映射；只处理已有账号键，排除 Hide |
| 材料、通用进化碎片、种子、兑换券 | 分类每项 +1000，可重复／撤销一次 | 单项或选中批量，目标数量／增加量 | 只开放已确认目录，不是游戏所有资源 |
| 小鱼干、普通／英雄试玩券 | 分别输入目标数量 | 单项或选中批量设置目标数量 | 留空不改，0 清零 |
| 磁带 | 全部获取至 1 | 选择磁带设为 1 | 原来超过 1 也会设为 1 |
| 蓝图 | 全部研究 | 选择需要研究的蓝图 | 已研究的保留 |
| 设施 | 补齐列表 | 选择需要补入的设施 | 保留已有记录 |
| 饰品 | 补齐并充能至 100 | 选择饰品补齐／充能 | 保留已有佩戴、图纸与符文；不提供换装编辑 |
| 武器获取次数 | 全部 +8 | 搜索名称／ID，选中 +8 或自定义非负增量 | 不下调次数；蓝图、科技等其他资格仍由游戏判断 |

## “设为”与“增加”的区别

以生物质原有 25 为例：

| 你的输入 | 预览结果 |
| --- | --- |
| 增加量 100 | 25 → 125 |
| 目标数量 100 | 25 → 100 |
| 目标数量 0 | 25 → 0 |
| 留空／增加量 0 | 不修改 |

同一项的目标值与增量互斥。当前只接受非负整数并检查整数溢出，这不是对游戏允许数量上限的承诺。先看逐项预览，再决定是否应用。

## 存档不同，可用按钮也不同

角色与宠物根据识别出的角色文件、账号 XML 判断；物品根据同账号物品分片判断；武器需要统计分片及同账号物品分片核对版本。**物品可以独立于角色文件使用**，角色读不到不一定代表物品也不可用。

当前物品与武器目录基准是 **8.6.0 / 80600**。文件缺失、账号不能配对、版本或结构不符时，相应功能会提示不可用；不要通过随意重命名另一账号文件来绕过检查。快捷武器操作会补入已知编号武器缺失的获取记录，专家模式也受已确认目录限制。

## 目前没有的功能

- 完整应用数据恢复、跨账号复制或 `.data.new` 恢复。2.0.3 支持本工具 ZIP 的限定范围导入与还原，详见[备份说明](backup-and-update.md)。
- `.data.new` 的读取、修改、删除或备份，以及独立的“强制读取本地”按钮。
- 云端登录、上传、下载或自动同步；需要使用游戏自己的云存档功能。
- 快速／专家模式没有自由角色等级、重新锁定、武器次数下调、饰品换装／符文编辑等预设操作。自由编辑可手动改文件，但不保证这些修改有效，也不修复分片关系。

本地读取开关的处理见[专门说明](local-data-reading.md)，备份与恢复范围见[备份说明](backup-and-update.md)。**新功能实际效果待用户验证；Root 文件读写最近设备测试：2026-10-09，不保证实际可用**；历史用户反馈与未验收范围见[开发状态](../development-status.md)。Python 桌面版有独立功能范围，见[桌面版说明](../../desktop/README.md)。
