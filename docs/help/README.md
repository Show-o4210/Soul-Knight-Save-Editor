当前 Android 版本为 **2.0.5-rc05**，适配《元气骑士》8.8.0，保留 8.6.0 和 8.7.0 支持。原版 8.8.0 已在 Android 9 模拟器核对铁矿和武器获取次数。配图沿用早期演示界面。 [发布说明](../releases/2.0.5-rc05.md) · [开发状态](../development-status.md)

本版包含蓝图与材料、普通武器进化、神话武器、XML 自由编辑、重新锁定与 `.data.new` 支持。B 站 8.7 已验证材料修改生效、未选材料保留；本版增加 Magisk 全局挂载备用，并回归光速普通 Root 读取；Shizuku Root 读取记录来自 rc02。
