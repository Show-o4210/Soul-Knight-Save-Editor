配置中的 `Locking` 实际是 0～8 的整数值，不是布尔开关；本轮未核实其全部业务含义，不据非零值排除皮肤。`Level` 是独立进化字段，不能作为有无皮肤的判断条件，本功能始终保留已有等级。

## 使用方式与写入规则

- 快速模式：“解锁已确认的全部武器皮肤”，只加入当前版本已确认的解锁串，保留当前皮肤与进化等级。
- 专家模式：按武器名、皮肤名或 ID 搜索；可以逐项解锁、解锁搜索结果，或单独选择当前皮肤。皮肤须已解锁或同时勾选本次解锁，才能切换使用；原皮肤始终可选。
- “使用可选的最高品质”是显式操作，只在已解锁及本次待解锁的皮肤中比较配置品质。同品质优先保留当前选择，否则按最小已确认索引稳定选择；不会默认把所有武器换肤。
- 缺少目录内武器记录时，创建该武器的 `Name`、`Level=0`、`CurrentSkinIndex=0` 和解锁列表；不会把进化等级设为 1。已有未知字段、未知皮肤串、收藏、抽取历史和其他武器记录保留。
- 当前索引为未核对的非负整数时，默认保留；用户仍可明确切换到已确认的可用皮肤。记录类型异常、`Name` 不匹配或解锁列表混入其他武器时，该武器不能修改；全量操作遇到异常条目会整体拒绝。

使用同账号 `weapon_evolution_data_<账号>_.data`，采用现有 DES-iambo 编码，并由同账号 `item_data` 的整数版本 80600／80700 选择目录。默认分片不替代账号分片，多份同账号分片不自动选择。仅修改皮肤分片及 XML 中已有的对应账号读取开关；不修改商店、碎片、获取次数或进化记录的其他字段。

新来源接入原生 Root 与 Shizuku Root 共用的扫描、固定路径刷新、预览、漂移检查、备份及事务恢复。快速／专家草稿分开，切换账号、游戏或访问方式后清空。仍不读取或修改 `.data.new`。
